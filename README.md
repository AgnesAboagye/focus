This project  developed as ontology-based data access and integratrtion (OBDI) framework  that extend Germinate with semantic capabilities.
The purpose was to make heterogeneous plant phenotypic and nutritional datasets easier to annotate, discover, query and compare across datasets, genotypes and crop species.
The resulting framework demonstrates how Germinate can support semantic discovery and comparison of phenotypic and nutritional data across datasets, 
genotypes and crop species while retaining the original Germinate data as the authoritative source.
